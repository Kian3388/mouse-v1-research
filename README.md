Mouse V1 Research

An ongoing computational neuroscience project investigating how neural activity in the mouse primary visual cortex (VISp) encodes visual stimulus direction.

Dataset: Allen Institute Visual Coding Neuropixels, session 757216464.

Current Progress

Loaded and explored the NWB recording.

Identified 261 VISp-associated units.

Examined unit quality and anatomical metadata.

Goal

Develop a reproducible neural decoding pipeline and eventually investigate an original research question in neural population coding.

Status

Early development. Results and methods are preliminary.
